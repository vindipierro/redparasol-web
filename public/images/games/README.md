# Official game artwork

Add approved source artwork here. Suggested naming:

- `seishun.webp`
- `oath-of-office.webp`
- `silk-road.webp`
- `command-authority.webp`

Use landscape 16:9 images for banners (ideally 1920x1080), and optimized images with descriptive alt text. Set `artwork` or `banner` in `src/data/games.ts` after adding each file. Do not use scraped or unrelated Roblox thumbnails.
